Sobre o projeto

Um laboratório pensado para os cinco Hands-On.

O website apresenta uma landing page simples em HTML, CSS e JavaScript. Cada exercício altera partes reais da interface e cria um histórico de evolução coerente.

O objetivo não é apenas executar comandos: é perceber como o Git apoia trabalho, colaboração e revisão de código.

Percurso prático

5 Hands-On, um único projeto

01

Preparar ambiente

Instalar Git, configurar identidade e preparar a conta GitHub.

02

Primeiro histórico

Inicializar o projeto, proteger ficheiros e criar commits claros.

03

Publicar no GitHub

Ligar o repositório remoto, criar README e analisar o histórico.

04

Branches e conflitos

Editar o footer em dois ramos e resolver um conflito real.

05

Colaboração

Clonar, abrir Pull Requests, rever código e integrar alterações.
